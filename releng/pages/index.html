Install

  1. In Eclipse: Help → Install New Software… → Add…
  2. Name Bella, location: the address above.
  3. Tick Bella and Bella ADT integration, finish and restart Eclipse.
  4. Set up Claude under Window → Preferences → Bella: with an API key or with your Claude subscription through the Claude Code CLI.

Bella uses the ABAP Development Tools you already have and does not install or update them. Later versions arrive through Help → Check for Updates.

Requirements

Eclipse 2024-12 or newer with Java 21 and SAP ABAP Development Tools.
